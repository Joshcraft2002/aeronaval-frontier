# Aeronaval Frontier

This repository only holds config and kubejs, refer to the modpack itself for the modlist

Datapacks included that aren't mine:
- [Minecolonies integration with Quark, 1.21.1+](https://www.planetminecraft.com/data-pack/minecolonies-integration-with-quark-1-21-1/)

- [True Ending - Ender Dragon Overhaul](https://modrinth.com/datapack/true-ending) (technically the datapack version)
