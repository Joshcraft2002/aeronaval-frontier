## Economy Guide
### Bounty Board
The first and main way to earn Spurs by turning in items for rewards. Find one in a village or similar structure to start, and more can be crafted later using Cogs (64 Spurs).

A board's decree determines what type of bounties are posted, but additional decrees can be crafted. There are three major categories:
- Industrial Arms
- Cuisine
- Engineering

### Delivery Quests Board
An alternate way to earn spurs by delivering cargo from one point to another
> Currently an issue with long cooldown times, looking into it

### Daily Shop
Where Spurs are spent. Most of its stock is building materials, but you can also get valuable items and consumables (such as fuel). It resets every 10 minutes.

### Create: Numismatics
Players can manually trade with each other, but [Create Numismatics](https://www.curseforge.com/minecraft/mc-mods/numismatics) provides other means to set up your own shop or other financial systems, on top of what base Create provides.
